Question 1

What is the missing value on the number lines below?
Marking criteriaMarks
Identifies the correct interval size for each number line1
Identifies the correct missing value for part (a)1
Identifies the correct missing value for part (b)1
(a)
The labelled values show that the number line increases by 7 each tick because:
−40 + 7 = −33
The missing value is one tick before −40.
−40 − 7 = −47
Answer: −47
(b)
The labelled values show that the number line increases by 8 each tick because:
−87 + 8 = −79
Count forward by 8 from −79 until the missing tick.
−79 + 8 = −71
−71 + 8 = −63
−63 + 8 = −55
−55 + 8 = −47
Answer: −47

Question 2

Marking criteriaMarks

Interprets the final answer in context1
(a)
A balance of −$32 means Peter owes $32, or his account is $32 below zero.
Answer: Peter is $32 in debt.
(b)
Starting balance = −$32
Payment received = +$50
−32 + 50 = 18
Answer: Peter’s balance would now be $18.
